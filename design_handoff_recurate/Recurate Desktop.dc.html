2Direction 1a — all remaining desktop screens (web · Windows · macOS share this layout)
Decisions. Sidebar replaces both the tab strip and every “← Back” button — every screen is one click away. Mini player stays on all screens except Now Playing (which is the player). Tool status pill, worker controls and Pending/Done/Failed counters use one shared visual. Bulk destructive buttons show their two-click confirm state in place. On macOS the sidebar gains 28px top inset for traffic lights; on Windows the window uses a custom titlebar merged into the sidebar header; on web the same layout renders in-browser (Tauri/PWA). Implementation spec in design_handoff_recurate/README.md.
